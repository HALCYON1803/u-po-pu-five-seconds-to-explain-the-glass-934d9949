One sentence a house cat says in its own defence, five seconds after
sweeping a glass off the table:

> There was another cat living in the glass, so I evicted him.

The glass was harbouring a rival cat — the cat's own reflection — so the
cat evicted the intruder. Territory, self-interest, zero remorse. No
apology, no confession, no gravity, no slippery edge, no
it-was-already-falling.

## Entry

`main.ts` writes the single sentence to `/output/entry.txt` (1–200
characters, one sentence, UTF-8). Run with Node:

```sh
node main.ts
```
